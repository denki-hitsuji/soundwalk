# 2026-02-22: SNS告知機能の強化

## 実施内容

### 新規ファイル
- `components/share/SharePostPreview.tsx` — 告知文プレビュー＋コピー＋X/LINEシェアボタンの汎用コンポーネント（`bare` propで外側sectionラッパー省略可能）
- `lib/utils/format.ts` — `fmtDateWithDay()`, `fmtTime()`, `fmtCharge()`, `normalizeHashtag()` 共通フォーマッタ
- `lib/utils/buildEventPost.ts` — イベント（企画）単位のSNS告知文生成
- `lib/utils/buildSchedulePost.ts` — 全ライブまとめ告知文生成（プロフィール名ヘッダー、act名・企画名・会場名表示）

### UI改善: パフォーマンス詳細ページ
- `app/musician/performances/[performanceId]/PerformanceDetailClient.tsx`
  - 旧: 「告知文をコピー」ボタンのみ（alert表示）
  - 新: `SharePostPreview` でプレビュー表示、コピー成功時のフィードバック改善、X/LINE共有ボタン
  - イベント紐付きの場合は「個別告知文」「企画全体の告知文」タブ切り替え
- `app/musician/performances/[performanceId]/page.tsx` — イベント出演者名一覧を取得し `eventActNames` として渡す

### 新機能: 企画SNS告知文
- `components/organizer/OrganizedEventDetailClient.tsx` — フライヤーの下に「企画SNS告知文」セクション追加
- テンプレート: 【ライブ告知】タイトル / 日時 / 会場 / CHARGE / ▼出演者一覧 / ハッシュタグ

### 新機能: まとめ告知文
- `app/musician/performances/PerformancesClient.tsx` — 「まとめて告知文」ボタン＋展開式プレビュー追加
- `app/musician/performances/page.tsx` — プロフィール名取得を追加
- フォーマット:
  ```
  プロフィール名

  ■ 2026/02/22（日）
  [アクト名]
  [企画名] @ [会場名]
  OPEN 16:30 / START 17:00
  ```

### UI改善: bands/[slug] 公開ページ
- `app/bands/[slug]/page.tsx` — UIリニューアル
  - プロフィール常時表示（photo + headline + body）、`<details>` 折りたたみ廃止
  - 日付を `YYYY/MM/DD（曜日）` にフォーマット
  - 未来/過去をセクション分離（過去は折りたたみ）
  - カードデザイン改善（rounded-xl, shadow-sm）
  - charge を `¥X,XXX` にフォーマット
