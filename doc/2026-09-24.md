# 2026-09-24: Googleログインの「provider is not enabled」エラー

## 症状

- Googleでログインしようとすると次のエラーが返る。
  `{"code":400,"error_code":"validation_failed","msg":"Unsupported provider: provider is not enabled"}`

## 原因

- Supabase（Soundwalkプロジェクト `tteglutuynkcapoqjipa`）でGoogleプロバイダーが有効になっていなかった。
- auth_logs に `GET /authorize` → 400 `provider is not enabled` が記録されていた（referer: `https://soundwalk.net/auth/callback`）。
- コード（`lib/auth/oauth.client.ts` の `signInWithOAuth({ provider: "google" })`）には問題なし。

## 対応

- Supabaseダッシュボードの Authentication → Sign In / Providers でGoogleを有効化し、Client ID と Client Secret を設定した（ユーザーが実施）。
- 確認する項目:
  - Google Cloud Console の承認済みリダイレクトURI: `https://tteglutuynkcapoqjipa.supabase.co/auth/v1/callback`
  - OAuth同意画面を「本番」にする
  - Supabase URL Configuration: Site URL `https://soundwalk.net`、Redirect URLs に `https://soundwalk.net/auth/callback`
- 設定後、ログインできることをユーザーが確認した。コードの変更はなし。
